## Функции
- Каталог из 13 фильмов.
- Поиск по названию, оригинальному названию, жанру и режиссёру.
- Фильтр по жанру и году, сортировка по названию, году и доступному внешнему рейтингу.
- Подробная страница: описание, режиссёр, год, жанр, длительность, актёрский состав и статус.
- Собственная оценка от 1 до 10.
- Мини-отзыв до 500 символов, имя/ник, дата публикации и удаление отзыва.
- Средняя оценка по отзывам, оставленным в данном браузере.
- "Избранное" показывает фильмы, по которым оставлены оценки/отзывы.
- Адаптивная сетка для мобильных экранов.

## Важно
Оценки, помеченные как внешний рейтинг, являются ориентировочными и могут меняться. У части новых фильмов общедоступный рейтинг не показан. Не путайте его со средней оценкой пользователей CineLib.
Оценки и отзывы хранятся в `localStorage` текущего браузера: они не синхронизируются между устройствами и не отправляются на сервер.

## Структура базы данных

База SQLite (`backend/cinelib.db`), три таблицы:

### users — пользователи
| Поле          | Тип      | Описание                        |
|---------------|----------|---------------------------------|
| id            | INTEGER  | Первичный ключ, автоинкремент   |
| name          | TEXT     | Ник пользователя                |
| email         | TEXT     | Уникальный email                |
| password_hash | TEXT     | Хеш пароля (bcrypt)             |
| created_at    | TEXT     | Дата регистрации                |

### movies — каталог фильмов
| Поле          | Тип      | Описание                        |
|---------------|----------|---------------------------------|
| id            | TEXT     | Первичный ключ (slug)           |
| title         | TEXT     | Название на русском             |
| original      | TEXT     | Оригинальное название           |
| year          | INTEGER  | Год выпуска                     |
| genre         | TEXT     | Жанры через " · "               |
| director      | TEXT     | Режиссёр                        |
| runtime       | TEXT     | Длительность                    |
| global_rating | REAL     | Внешний рейтинг (nullable)      |
| status        | TEXT     | Статус релиза                   |
| cast          | TEXT     | Актёры                          |
| description   | TEXT     | Полное описание                 |
| short_desc    | TEXT     | Краткое описание                |
| poster        | TEXT     | Путь к постеру                  |
| theme         | TEXT     | Цветовая тема карточки          |

### reviews — отзывы (связывает users и movies)
| Поле         | Тип      | Описание                          |
|--------------|----------|-----------------------------------|
| id           | TEXT     | Первичный ключ                    |
| movie_id     | TEXT     | Внешний ключ → movies.id          |
| user_id      | INTEGER  | Внешний ключ → users.id           |
| rating       | INTEGER  | Оценка 1–10 (CHECK-ограничение)   |
| text         | TEXT     | Текст отзыва                      |
| created_at   | TEXT     | Дата создания                     |

Связи:
- users 1──N reviews (один пользователь может оставить много отзывов)
- movies 1──N reviews (к одному фильму много отзывов)
